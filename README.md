## Description

A simple two-player Pong game made with LÖVE2D. Each player controls a paddle and tries to bounce the ball back toward the other player. The ball bounces off the paddles and the top and bottom edges of the window.

## How to Run

Install LÖVE2D and make sure the `love` command is available in your terminal. Open a terminal in the project folder and run:

```powershell
love .
```

## Controls

- Left paddle: W to move up and S to move down.
- Right paddle: Up arrow to move up and Down arrow to move down.

## Own Feature

Each paddle has a different color: the left paddle is blue, and the right paddle is orange.
